# R2 composed-objective recovery protocol

Prepared before R2 execution,2026-09-23. Requires completed, verified K1 and its
saved K2 coefficient proposal. R2 tests the new opt-in research_objective_v1 with
explicit nine-family and three-regularizer coefficients, fixed facade allowance,
radius6/envelope budget and hard_preclamp coverage. Default recipe mass_3 is a
sensitivity candidate, not a validated optimum. Four logical updates only.

Preserve R1's four separate-process branches: uninterrupted4,prefix2,resume2,
repeat-resume2, ten executed updates. Model/Adam/StepLR/checkpoint metadata and
four RNG streams must match exactly, as must losses/fields. Cycle three scenes
legacy000,ground-pair,minimal so all are exercised. NumPy draw is independently
recorded; Python selects2-4 steps and explicit firing RNG drives dynamics.
No sample pool, CUDA or mixed precision. Completed-update CPU boundaries only.

Metadata includes full coefficients, scene hashes, original checkpoint hash,
composition/facade/regularizer/recovery/runner source hashes, K2 proposal hash,
optimizer/scheduler choices, seed and cyclic scene rule. No overwrite, paid
compute, production switch or architectural-quality claim. A success validates
restart for this composed objective, not the later complete K2 trainer.
