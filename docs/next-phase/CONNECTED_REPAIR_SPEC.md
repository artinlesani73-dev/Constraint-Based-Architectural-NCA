## Versioned update rule (provisional experiment CGR1)

Use current 32-cubed grid and seven static context channels. Keep60->64->8
pointwise network dimensions and central-difference perception, but change the
state/output semantics. Parameters must be freshly initialized, never loaded
from NR5 solely because tensor shapes match. Initialization seed1201, last-layer
weights/biases zero. Seven hidden channels start zero.

Let M_t be binary accepted occupancy, initially the damaged input I. Let A be
permitted AND domain. Reject input outside A; do not silently discard it.
Let N6(M_t) be the union of six face neighbors with zero exterior padding.
F_t = A AND NOT M_t AND N6(M_t). Compute this synchronously from the previous
occupancy, not in-place inside a scan. Edge/corner contact alone is insufficient.

Network input: perception of [float(M_t), H_t] concatenated with perception of
the unchanged seven context channels. Eight network outputs mean one proposal
logit l_t and seven hidden-state increments. Proposal probability q_t=sigmoid(l_t).
Sample B_t~Bernoulli(0.5) independently per cell with the checkpointed firing RNG.
M_(t+1) = M_t OR (F_t AND B_t AND (q_t>0.5)).
H_(t+1) = (H_t + B_t * delta_H_t) * A.
Hidden communication can occur anywhere legal; accepted geometry can grow only
on the occupied face frontier. Preserve every accepted cell, not just I.

This is learned proposal scoring plus an explicitly constrained constructive
update. Legality, preservation and growth attachment are enforced, not learned.
Accepted occupancy is the evaluated output. Unconstrained q_t, birth masks and
initial/final occupancy must also be retained so enforcement is visible.
No cleanup, oracle target mask, flood-fill pruning or threshold adjustment.

Guarantee: each new cell has a face-connected path to some original input cell,
because births attach to the prior accepted set and accepted cells never vanish.
If I is a single connected component, this prevents newly detached components.
If I has multiple components, it does NOT guarantee they merge, touch both
interfaces, have adequate bulk or satisfy geometric support. Empty I cannot
grow; fail clearly as outside this repair task. Existing input defects persist.
An incorrect accepted birth cannot be retracted; this is an explicit tradeoff,
not a general-purpose corruption-repair model.

## Training supervision and gradients

Use model-generated occupancy trajectories, not target-forced growth. Target
is supervision only, never network context, frontier construction or decoder.
Keep hard occupancy decisions detached. Do not claim end-to-end gradients through
Boolean birth decisions and do not silently introduce straight-through gradients.
Hidden-state recurrence remains differentiable across32steps.

Apply a loss at EACH step, before committing that step's births. Supervise logits
on fired frontier E_t=F_t AND B_t. Positive set E_t AND T, negative set E_t AND NOT T.
L_frontier = 0.5*mean(softplus(-l_t) on positives)
           + 1.0*mean(softplus(l_t) on negatives).
For intact examples use1.5 negative coefficient, with positives empty.
An empty class contributes exactly zero; no division by zero. Keep the case
classification based on I==T, not the current evolving occupancy.

Define one-step soft candidate P_t = float(M_t)+float(E_t)*q_t. This is in[0,1].
Use valid, stride1,3x3x3 mean pooling in the32-cubed world: no padded windows.
Let W_t be windows touching E_t (max pooling of E_t). L_volume is mean absolute
difference between pooled P_t and pooled T over W_t; empty W_t contributes zero.
L_t=L_frontier+0.25*L_volume. Total loss=mean(L_t over exactly32steps).
The3-cell cube corresponds to2.4m, matching the existing thickness scale. This
local-volume surrogate is not the exact bulk predicate or structural loss.
Supervision at birth time supplies a penalty before an irreversible wrong birth;
later steps cannot differentiate through earlier hard decisions. Distant missing
cells get no frontier gradient until growth reaches them. These are optimization
risks to test, not proven solutions.

This changes update semantics and objective together as one constructive repair
system. A single comparison can assess the package, not causally attribute gains
to the gate versus the neighborhood loss. No architecture or loss-weight sweep.
