# Experiment index

Small immutable attempt summaries live in `records/` and are tracked in Git. Full source snapshots, logs, tensors, checkpoints and images live in the local artifact store and Google Drive once configured. Never treat a synthetic regression run as a model-quality benchmark.

See `docs/next-phase/EXPERIMENTS.md` for the evidence contract and `docs/next-phase/RESUME.md` for the latest completed attempt. Preserve failed and interrupted summaries. Add a linked new attempt rather than rewriting history.
